How It Works

1. Access from Menu Bar

Click the File Cabinet Pro icon in your menu bar. Choose icon, list, column, or cover flow view to browse files and folders instantly.

2. Manage Files

Select files to rename, tag, copy, move, compress, or trash. Right-click for context menu. Preview with spacebar or show in Finder.

3. Edit & View

Open text, images, PDFs, or media natively. Edit with built-in tools—rotate images, revert versions, or create from clipboard/Finder.

4. Customize

Add favorites to sidebar, set hotkey or auto-launch, tint folders. Access settings for precise control over views and behavior.

FAQ

Is this the full version?

Yes, File Cabinet Pro 8.8.2 is fully activated. No purchases or subscriptions needed—enjoy all features immediately.

Does it support my file types?

Handles text (TXT, RTF, RTFD, MD, PDF), images (PNG, JPEG, TIFF, BMP, PSD/SVG import), and media (MOV, MP4, MP3, WAV, more). Edit, view, or open in apps.

How do I set it up?

Install and it runs from the menu bar. Enable Finder extension in System Settings > Extensions for document creation. Optional: set hotkey or login launch in preferences.

What’s new in 8.8.2?

Custom folder colors, faster external volumes, smarter batch error alerts, dedicated column settings tab, and minor fixes for smoother performance.

Works on my Mac?
